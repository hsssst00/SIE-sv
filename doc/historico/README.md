# Historia heredada de SIE-el-salvador

SIE-sv se separó de `hsssst00/SIE-el-salvador` el 2026-11-22 (ADR-011). Esta carpeta guarda la documentación de las
Fases 0 a 7 de ese proyecto, que SIE-sv hereda pero ya no sigue. Los documentos se movieron sin editar (git los
registra como renombres al 100 %). Por eso sus enlaces y rutas internas son las de entonces: donde dicen `doc/X`, el
archivo está ahora en `doc/historico/X`, salvo los que siguen vivos en SIE-sv (`doc/adr/`, las bitácoras, los
calendarios y el manual).
