# Fuentes pendientes (fuera del catálogo de SIE-sv)

Estas 45 publicaciones estaban inventariadas en el catálogo heredado de `SIE-el-salvador`, pero nunca se capturaron, y
salieron del catálogo de SIE-sv el 2026-11-22 (ADR-012). Sus fichas completas siguen en `SIE-el-salvador` y en el
historial de git de este repositorio. Para que una entre a SIE-sv hay que comprobar que **no tiene API** (ADR-012,
punto 1), escribir su ficha en `catalogos/01_publicaciones/` y preguntar antes (regla 4). Esta lista no afirma cuáles
tienen API: eso se verifica caso por caso.
